🧱 Concrete Strength Prediction API

This API predicts the compressive strength of concrete based on its mix composition and curing age.

🔹 Endpoint

POST /predict

🔹 Parameters

Parameter Type Required Description
cementfloatYesAmount of cement (kg/m³)
blast_furnace_slagfloatYesBlast furnace slag (kg/m³)
fly_ashfloatYesFly ash (kg/m³)
waterfloatYesWater (kg/m³)
superplasticizerfloatYesSuperplasticizer (kg/m³)
coarse_aggregatefloatYesCoarse aggregate (kg/m³)
ageintYesCuring age (days)
